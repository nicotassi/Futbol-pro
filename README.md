# FUTBOLISTA PRO

**Entrená. Aprendé. Evolucioná.**

Aplicación web progresiva (PWA), mobile-first, privada, para el seguimiento y desarrollo del rendimiento futbolístico de un jugador infantil. Dos perfiles: jugador y administrador (papá).

## Estado del proyecto

| Fase | Contenido | Estado |
|---|---|---|
| 0 | Análisis del entorno, arquitectura y plan | ✅ Propuesta lista — **pendiente de validación** |
| 1 | Diseño, estructura, navegación, PWA base | ⏳ Planificada |
| 2 | Supabase: base de datos, usuarios, RLS | — |
| 3 | Entrenamiento: biblioteca, constructor, modo entrenamiento | — |
| 4 | Partidos, bienestar, objetivos, evaluaciones | — |
| 5 | Registro del reloj con IA y validación manual | — |
| 6 | Evolución, gráficos, calendario, logros | — |
| 7 | Pruebas en Android y publicación | — |

Todavía no hay código de la aplicación: primero se valida la arquitectura.

React + TypeScript + Vite · Tailwind CSS · React Router · vite-plugin-pwa · Supabase (PostgreSQL, Auth, RLS, Storage, Edge Functions) · Claude API (visión) desde backend.
